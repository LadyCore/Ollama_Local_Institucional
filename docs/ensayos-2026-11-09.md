## Comprobaciones CLI y fallo de resolución del modelo

Comandos ejecutados según el informe; la ruta de salida se representa mediante un parámetro sustituible:

```sh

ollama list

ollama show --modelfile qwen3-estudio > <archivo-modelfile>
grep -E '^(FROM|PARAMETER|SYSTEM)' <archivo-modelfile>
ollama --version
ollama run --help
ollama run qwen3-estudio --think=false
ollama run --think=false qwen3-estudio
ollama run qwen3-estudio:latest --think=false
ollama run qwen3-estudio:latest
systemctl status ollama --no-pager
systemctl show ollama -p User -p Environment
getent passwd ollama
```

Se intentó consultar el manifiesto remoto en registry.ollama.ai, ruta /v2/library/qwen3-estudio/manifests/latest. Falló la consulta DNS con «write: operation not permitted». El servicio permanecía active (running), con GET /api/tags 200, POST /api/show 404 e intento POST /api/pull en los registros examinados.

La causa por la que el modelo figura en el inventario pero falla su resolución durante esos intentos queda abierta. El fallo se reprodujo sin --think=false. No hubo desactivación permanente del razonamiento ni cambios informados de parámetros o configuración permanente del servicio.
